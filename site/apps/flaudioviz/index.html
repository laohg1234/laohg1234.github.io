01

Import a song

Choose a local audio file. It stays in this browser and is not uploaded.

  1. Add audioChoose or drop an MP3, WAV, OGG, FLAC, or M4A file. Browser support decides which formats can be decoded; WAV and MP3 are the safest choices.
  2. Add a coverChoose PNG, JPG, or WebP. Supported audio tags may also fill the cover, title, artist, album, genre, and track number automatically.
  3. Import lyricsChoose or drop an .lrc file. Timed lines follow playback and appear in the preview and exported video.
  4. Check song informationEdit the title, artist, album, genre, BPM, or track number. The title, artist, album, and track number appear in the preview and exports. Estimate BPM gives the whole song one BPM value; it does not make a changing BPM timeline.
  5. Check audio detailsAfter the file loads, this panel shows the sample rate, channels, available bit depth, file size, peak headroom, and decode state. These values are read-only.
Good to knowA .flavsettings file restores a saved setup, but it does not include the audio or cover. Choose those files again after importing.
02

Preview and playback

PNG and MP4 exports use the scene shown in the large preview. Use the controls below it to listen or jump to different parts of the song while you adjust the design.

Back, play, and forward
Jump back or forward by 10 seconds, or start and pause playback. The time readout shows the current position and total duration.
Song position
Drag the long slider to seek. If the song was playing, it pauses while you drag and resumes when you release it.
Mute
Mute only affects what you hear during preview. It does not remove audio from an exported MP4. The mute button is hidden on very narrow screens to preserve space.
Rolling title
Long titles scroll only when they do not fit. Reduce motion keeps the title still.
ShortcutsWhen you are not typing in a field, Space plays or pauses; Left and Right move by 5 seconds.
03

Layers and meters

Every switch in Layers and meters changes a visible part of the exported visual. Turn off anything you do not need.

Cover and cover track
Cover hides the artwork. Cover track controls the two thin animated lines beside it independently.
BPM display and beat rail
Shows the current BPM and the small left-right beat indicator. It uses the BPM field unless the action list supplies timed BPM changes.
Spectrum and waveform
Spectrum shows the current frequency energy. Waveform shows the song's overall shape and current short-window energy.
Grid and particles
These are background guides and small drifting points. They can be removed without affecting audio analysis.
Progress and timeline times
Progress is the thin line inside the exported picture. Timeline times controls its start and end labels; the webpage playback slider remains separate.
Lyrics
Shows the current timed line from the imported .lrc file. This switch also controls lyrics in PNG and MP4 exports.
Source labels and right-side details
File source label, right-side source, and right-side duration can each be hidden.

Bottom meters

Peak
The highest detected level.
RMS and loudness estimate
Both use average signal energy, so their values may be close. Neither is a LUFS measurement.
Dynamic range estimate
Short-window RMS variation. It is a visual estimate, not LUFS LRA.
Crest factor
The difference between peak and average level.
Duration
The full decoded song length.
04

Visual tuning

Colors
Adjust the background, text, primary, and secondary colors separately. Shuffle palette tries another combination. Reset colors restores only the current theme, and light and dark themes keep separate colors.
Bar width and spectrum energy
Bar width changes the number and spacing of spectrum bars. Spectrum energy changes how strongly the graph responds.
Waveform height
Makes the waveform taller or shorter without changing the music file.
Motion
This mainly controls how fast and how far the particles and cover track move. Set it to 0 to stop those decorative movements.
Frequency scale
Logarithmic gives more room to bass and mids, similar to how we hear. Linear spreads frequencies evenly.
FFT size
Higher values separate nearby frequencies more clearly but react a little less quickly. The default is 16384 and works well for most songs.
Spectrum style
Choose bars, line, or dots. Bars are the default.
05

Layout and reduced motion

Split
The default layout puts the cover on the left and the title and graphs on the right. It works well for landscape video.
Stack
The cover sits higher, with the other information arranged below it. Choose this when you want the cover to stand out.
Minimal
Uses a smaller, tighter arrangement. It does not automatically hide the cover, but the cover track is omitted in this layout.
Show labels
Hides descriptive labels, frequency markings, meter names, and canvas timeline times for a cleaner picture.
Reduce motion
This stops title scrolling, particle drift, and moving cover-track highlights. The spectrum and waveform still react to the music.
Good to knowTurn on Reduce motion if moving visuals feel uncomfortable, you want a steadier result, or preview feels choppy on your device.
06

Action list

Use the action list as notes tied to points in the song. A bpm or tempo line changes the BPM display and beat movement from that time onward; other text is only saved as a note.

00:00.000  bpm 175.90
00:12.500  tempo value=118.75
00:24.000  note text=section-2
Time stamp
Use MM:SS.sss, HH:MM:SS.sss, or a number of seconds. Empty lines and lines beginning with # are ignored.
bpm / tempo
These are the only action types that currently change the visual. Enter a positive BPM after the command.
beat / note and other text
Saved as notes only. They do not yet change colors, captions, or scenes.
Copy time
Copies the current playback position so you can paste an exact time stamp.
Add action
Inserts a note with the current playback time wherever your text cursor is.
Import and save
Only .flavactions files can be imported. Save list opens Save As and creates a .flavactions file.
ImportantThe list is saved in this browser as you type. Saving a .flavactions file is still recommended before clearing browser data or moving to another device.
07

Save and export

Save preset / Import
A .flavsettings file stores the visual setup, song information, export choices, and action list. It does not contain audio or cover files. Importing may replace the current setup.
Reset
Restores visual and color defaults only. It does not erase song information, the action list, or export settings.
Export PNG
Saves the picture at the current playback position using the selected canvas size.
Export MP4
Exports the full-song visual and audio as an MP4. A current version of Edge or Chrome is recommended, and you can stop the render at any time.
Canvas size and frame rate
Choose 720p, 1080p, square, or custom dimensions. Frame rate accepts your own positive whole number; higher values take longer and the page will warn you if the job is too large for the browser.
Where files go
Supported browsers let you choose a location with Save As. Otherwise, the file uses your browser's usual download behavior.
FLAudioViz attribution
MP4 places “Made with FLAudioViz” in the lower-right corner.
08

Recovery and version

Automatic local saving
Song information, visual settings, export options, and actions are saved automatically in this browser. Audio and cover files are not included, so choose them again after restoring.
Recovery prompt
When saved work is found after reopening, choose Restore to bring it back or Start fresh to clear it. After restoring, choose the audio and cover again.
Top-bar controls
More jumps to the main areas. EN / 中 changes language. The sun button changes theme, the help button opens this guide, and the sliders button jumps to customization.
Version check
The version button in the footer reads the FLAudioViz version included with this site; it does not check online for updates. If the version cannot be read, the button changes to Retry.
